# Visor Urbano SPGG (Android)

App Android con pantalla de inicio propia (logo Un Solo San Pedro) que abre el Visor Urbano oficial
(https://visorurbano.sanpedro.gob.mx/) directamente dentro de la app, con selección de predios,
ubicación y todas sus funciones.

Cada cambio en `main` compila el APK automáticamente (GitHub Actions) y lo publica en **Releases**.

Descarga: pestaña Releases > VisorUrbanoSPGG.apk
